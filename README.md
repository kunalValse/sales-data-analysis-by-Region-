# Sales Performance MIS Report
## Excel · SQL

### Project Overview
Built an end-to-end MIS and analytics report for a 
fictional financial products dataset covering loan 
sales across regions, channels, and products 
(Jan–Mar 2025).

### Dataset
- 500+ rows of transactional sales data
- Columns: Date, Product, Category, Region, 
  Channel, Units Sold, Revenue, Cost, Inventory
- Created independently for portfolio purposes

### What Was Done
- Data cleaning and validation in Excel
- Pivot table analysis — profitability, channel 
  contribution, regional performance, 
  inventory vs sales
- SQL queries for product revenue, 
  channel analysis, and inventory comparison

### Key Insights
- Online channel drove highest revenue (₹28.5M)
- Loan A was top performing product (₹13.8M)
- North region contributed highest sales volume
- Average profit margin across all products: ~27%
